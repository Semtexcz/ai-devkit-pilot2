# ai-devkit-pilot2

A small Python script project.

This project was created with native [`uv init`](https://docs.astral.sh/uv/) and
the [ai-devkit](https://github.com/Semtexcz/ai-devkit) standards overlay. uv owns
`pyproject.toml`, `uv.lock`, `.venv/` and `main.py`; the overlay owns
`AGENTS.md`, `mise.toml`, the checker configuration and the documentation seeds.
See [File ownership](docs/explanation/ownership.md).

## Requirements

- Linux x86-64: the only platform this overlay has been verified on.
- [mise](https://mise.jdx.dev/) 2026.11.1 or newer.
- Git, once you start versioning the project.

## Quick start

```bash
mise trust                 # read mise.toml first, then trust it
mise install               # install the pinned Python, uv, Node.js and OpenSpec
uv sync --locked           # create .venv from uv.lock
openspec init --tools opencode,codex --profile core   # once, before the first check
mise run check             # run every check
mise run start             # run main.py
```

`mise run check` validates the OpenSpec specifications, and OpenSpec refuses to run
outside an initialized project, so initialize it once after cloning. The command
above configures OpenCode and Codex; see
[docs/how-to/use-openspec.md](docs/how-to/use-openspec.md) for another agent.

## Commands

| Command | Runs |
|---|---|
| `mise run start` | `uv run --locked python main.py` |
| `mise run check` | every check below, in the listed order |
| `mise run lint` | `uv run --locked ruff check .` |
| `mise run format-check` | `uv run --locked ruff format --check .` |
| `mise run typecheck` | `uv run --locked mypy --strict main.py` |
| `mise run test` | `uv run --locked pytest` |
| `mise run docs` | `uv run --locked zensical build --strict` |
| `mise run spec-check` | `openspec validate --all --strict --no-interactive` |

The native commands, the pinned versions and the lockfile procedure are in
[docs/reference/commands.md](docs/reference/commands.md).

## Layout

```text
.
├── AGENTS.md            engineering rules for people and agents
├── CHANGELOG.md         notable changes to this project (owned by you)
├── main.py              application entry point (owned by you)
├── mise.toml            pinned tools and task definitions
├── mise.lock            locked tool versions, generated by `mise lock`
├── mypy.ini             type-checking policy
├── openspec/            specifications and proposed changes (owned by OpenSpec)
├── pyproject.toml       project metadata and dependencies (owned by uv)
├── pytest.ini           test discovery
├── ruff.toml            lint and format policy
├── uv.lock              Python dependency lockfile (owned by uv)
├── zensical.toml        documentation site configuration
├── .agents/             OpenSpec skills for Codex (generated)
├── .opencode/           OpenSpec commands and skills for OpenCode (generated)
├── docs/                Diátaxis documentation
├── site/                generated documentation output (ignored)
└── tests/               automated tests
```
